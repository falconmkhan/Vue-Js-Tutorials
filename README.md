# Vue.js Tutorial 

This repository contains my **Vue.js learning journey**, where I practice and implement core Vue concepts through small examples and mini projects.

It is mainly focused on understanding Vue fundamentals and building confidence to create frontend projects using Vue.

---

## Topics Covered

- Vue project setup
- Components, child - parent component
- Event handling
- Binding, Html Binding 
- If else Statement
- (`ref`, `fetch`)
- Loops
- Form handling, Form Validation
- Interpolation
- Methors Params
- Project structure & best practices

---

## Tech Stack

- **Vue.js**
- **JavaScript**
- **HTML5**
- **CSS3**
- **Vue Router**
